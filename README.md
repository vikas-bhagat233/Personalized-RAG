# Personalized RAG System 📚

A powerful Retrieval-Augmented Generation (RAG) system for processing and querying personal documents using Google's Gemini AI.

## 🌟 Features

- **PDF Document Processing**: Upload and process multiple PDF documents
- **Intelligent Retrieval**: FAISS-based vector search for relevant document chunks
- **AI-Powered Answers**: Uses Google's Gemini models for accurate responses
- **Source Citations**: Shows sources for generated responses
- **Chat Interface**: Interactive chat with your documents
- **Persistent Storage**: Saves processed documents and indexes
